# Superman SMES Data

Simulated data for 47 participants rating Superman media on the
Subjective Media Experience Scale (SMES), grouped by height gap between
the Superman and Lois Lane actors.

## Usage

``` r
superman_smes
```

## Format

A data frame with 47 rows and 5 variables:

- num:

  Unique participant number

- height_gap:

  Height gap category: Minimal (1), Average (2), Big (3)

- emotional_impact:

  Emotional Impact subscale (sum of 4 items, range 4-20)

- aesthetic_appeal:

  Aesthetic Appeal subscale (sum of 3 items, range 3-15)

- cognitive_engagement:

  Cognitive Engagement subscale (mean of 4 items, range 0-7)
