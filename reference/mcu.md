# MCU Films Data

Data on Marvel Cinematic Universe films through the Infinity Saga,
including box office performance and Rotten Tomatoes scores.

## Usage

``` r
mcu
```

## Format

A data frame with variables:

- movie:

  Title of the movie

- length_hrs:

  Movie length: hours portion

- length_min:

  Movie length: minutes portion

- release_date:

  US release date

- opening_weekend_us:

  Opening weekend US box office (unadjusted)

- gross_us:

  Total US box office (unadjusted)

- gross_world:

  Total worldwide box office (unadjusted)

- phase:

  MCU Phase: 1, 2, or 3

- critics:

  RT critics score (0-100)

- audience:

  RT audience score (0-100)

- favor:

  Whether critics (1) or audience (2) score is higher

## Source

Internet Movie Database
