# Football Concussion Brain Data

Brain measurements comparing football players (with and without
concussion history) to non-football-playing controls.

## Usage

``` r
football
```

## Format

A data frame with 3 variables:

- group:

  Control (1), Football no concussion (2), Football with concussion (3)

- years:

  Years of football played

- volume:

  Total hippocampus volume in cubic centimeters

## Source

Singh R, Meier T, et al., JAMA, 311(18), 2014.
