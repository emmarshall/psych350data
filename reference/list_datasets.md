# List all available datasets in psyc350data

List all available datasets in psyc350data

## Usage

``` r
list_datasets()
```

## Value

Character vector of dataset names.

## Examples

``` r
list_datasets()
#>  [1] "superman"      "superman_smes" "hot_ones"      "tip_jokes"    
#>  [5] "mcu"           "mock_jury"     "candy"         "candy_simple" 
#>  [9] "affairs"       "football"     
```
