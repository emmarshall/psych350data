# Tip-Jokes Experiment Data

Data from Gueguen (2002) examining whether a waiter leaving a joke or an
advertisement on a card affects tipping behavior.

## Usage

``` r
tip_jokes
```

## Format

A data frame with variables:

- card:

  Type of card: Advertisement (1), Joke (2), None (3)

- tip:

  Whether customer left a tip: No (0), Yes (1)

- ad:

  Indicator for ad card: 0/1

- joke:

  Indicator for joke card: 0/1

- none:

  Indicator for no card: 0/1

## Source

Gueguen, N. (2002). Journal of Applied Social Psychology.
