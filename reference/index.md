# Package index

## Datasets

All available datasets for PSYC 350 labs

- [`superman`](https://emmarshall.github.io/psych350data/reference/superman.md)
  : Superman Actor Data
- [`superman_smes`](https://emmarshall.github.io/psych350data/reference/superman_smes.md)
  : Superman SMES Data
- [`hot_ones`](https://emmarshall.github.io/psych350data/reference/hot_ones.md)
  : Hot Ones Guest Data
- [`tip_jokes`](https://emmarshall.github.io/psych350data/reference/tip_jokes.md)
  : Tip-Jokes Experiment Data
- [`mcu`](https://emmarshall.github.io/psych350data/reference/mcu.md) :
  MCU Films Data
- [`mock_jury`](https://emmarshall.github.io/psych350data/reference/mock_jury.md)
  : Mock Jury Data
- [`candy`](https://emmarshall.github.io/psych350data/reference/candy.md)
  : Candy Rankings Data (Full)
- [`candy_simple`](https://emmarshall.github.io/psych350data/reference/candy_simple.md)
  : Candy Rankings Data (Simplified)

  : Extramarital Affairs Data
- [`football`](https://emmarshall.github.io/psych350data/reference/football.md)
  : Football Concussion Brain Data

## Export Functions

Export datasets as SPSS .sav files

- [`export_sav()`](https://emmarshall.github.io/psych350data/reference/export_sav.md)
  : Export a dataset as an SPSS .sav file
- [`export_all_sav()`](https://emmarshall.github.io/psych350data/reference/export_all_sav.md)
  : Export all psyc350data datasets as SPSS .sav files
- [`list_datasets()`](https://emmarshall.github.io/psych350data/reference/list_datasets.md)
  : List all available datasets in psyc350data
