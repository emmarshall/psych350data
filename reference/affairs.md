# Extramarital Affairs Data

Cross-section data from a 1969 Psychology Today survey on extramarital
affairs.

## Usage

``` r
affairs
```

## Format

A data frame with variables:

- affairs:

  Frequency of affairs (0, 1, 2, 3, 7, 12)

- gender:

  Female (1), Male (2)

- age:

  Age in years (bracket midpoints)

- yearsmarried:

  Years married: \<7 (1), 7-\<10 (2), 14+ (3)

- children:

  Children: No (1), Yes (2)

- religiousness:

  Religiousness (1-5 scale)

- education:

  Education level (9-20)

- occupation:

  Hollingshead occupation (1-7)

- rating:

  Marriage self-rating (1-5)

## Source

Fair, R.C. (1978). Journal of Political Economy.
