# Candy Rankings Data (Full)

Data on 85 candy types with ingredient indicators, sugar/price
percentiles, and win percentages from 269,000 matchups.

## Usage

``` r
candy
```

## Format

A data frame with 85 rows and 13 variables:

- competitorname:

  The name of the candy

- chocolate:

  Contains chocolate? (0=No, 1=Yes)

- fruity:

  Fruit flavored? (0=No, 1=Yes)

- caramel:

  Contains caramel? (0=No, 1=Yes)

- peanutyalmondy:

  Contains peanuts/almonds? (0=No, 1=Yes)

- nougat:

  Contains nougat? (0=No, 1=Yes)

- crispedricewafer:

  Contains crisped rice/wafers? (0=No, 1=Yes)

- hard:

  Hard candy? (0=No, 1=Yes)

- bar:

  Candy bar? (0=No, 1=Yes)

- pluribus:

  One of many in bag/box? (0=No, 1=Yes)

- sugarpercent:

  Sugar percentile within dataset

- pricepercent:

  Unit price percentile

- winpercent:

  Win percentage from 269,000 matchups

## Source

FiveThirtyEight candy power rankings
