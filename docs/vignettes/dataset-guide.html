How Categorical Variables Work

In R: Categorical variables use human-readable character values (e.g., "Film", "TV Series", "Minimal").

In SPSS exports: These are automatically converted to numeric codes with value labels.

# Example: categorical variables are human-readable in R
superman |>
  select(num, media, type, height_gap) |>
  head(4)
#> # A tibble: 4 × 4
#>     num media               type    height_gap
#>   <int> <chr>               <chr>   <chr>     
#> 1     1 Superman            Film    Big       
#> 2     2 Superman: The Movie Film    Big       
#> 3     3 Smallville          TV Show Average   
#> 4     4 Superman Returns    Film    Big
