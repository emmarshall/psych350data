Getting Started with psych350data

Overview

The psych350data package provides all the datasets you need for PSYC 350 labs. Each dataset is pre-cleaned and ready to use in two ways:

  1. In R — Datasets use human-readable values (like “Film”, “TV Series”) and standard NA for missing data. Perfect for analysis with psych350lab functions.

  2. In SPSS — Export functions create .sav files with numeric codes, value labels, and -99 for missing values.

Loading the Package

library(psych350data)
library(dplyr)

#> Attaching package: 'dplyr'

Using Datasets in R

Every dataset is a tibble that’s immediately available after loading the package. Categorical variables use descriptive character values that are easy to read and work with:

# Categorical variables are human-readable
superman |>
 select(num, media, type, clark_grp, height_gap) |>
 head()
#> # A tibble: 6 × 5
#>     num media                   type    clark_grp     height_gap
#>   <int> <chr>                   <chr>   <chr>         <chr>     
#> 1     1 Superman                Film    6ft or taller Big       
#> 2     2 Superman: The Movie     Film    6ft or taller Big       
#> 3     3 Smallville              TV Show 6ft or taller Average   
#> 4     4 Superman Returns        Film    6ft or taller Big       
#> 5     5 Superman & the Mole Men Film    6ft or taller Big       
#> 6     6 Man of Steel            Film    6ft or taller Big

Missing Values in R

Missing values are represented as NA, which R functions handle automatically:

# See which Superman entries have missing Letterboxd scores
superman |>
 select(num, media, ldb_likes, ldb_scores) |>
 filter(is.na(ldb_scores))
#> # A tibble: 6 × 4
#>     num media                                        ldb_likes ldb_scores
#>   <int> <chr>                                            <dbl>      <dbl>
#> 1     3 Smallville                                          NA         NA
#> 2     7 Superman                                            NA         NA
#> 3     8 Superman & Lois                                     NA         NA
#> 4     9 Lois & Clark: The New Adventures of Superman        NA         NA
#> 5    10 The Adventures of Superboy                          NA         NA
#> 6    11 The Adventures of Superboy                          NA         NA
# R functions handle NA automatically
mean(superman$rt_critics_score, na.rm = TRUE)
#> [1] 79.375

Converting to Factors for Analysis

For some analyses (like ANOVA), you may want to convert character variables to factors:

# Convert for analysis - order levels as needed
superman_for_analysis <- superman |>
 mutate(
    type = factor(type),
    clark_grp = factor(clark_grp),
   height_gap = factor(height_gap, levels = c("Minimal", "Average", "Big"))
 )

# Now ready for ANOVA, contrasts, etc.
levels(superman_for_analysis$height_gap)
#> [1] "Minimal" "Average" "Big"

Preparing Data for SPSS-Matched Analysis

If your analysis needs to produce numeric output that matches SPSS — for example, when comparing R results to SPSS output from a lab assignment — use the prep functions to convert categorical variables to the same numeric codes SPSS uses.

The prep_data() Function

prep_data() is the main entry point. Pass it a dataset and the dataset name as a string:

superman_prepped <- prep_data(superman, "superman")

superman_prepped |>
  select(num, media, type, clark_grp, height_gap) |>
  head()
#> # A tibble: 6 × 5
#>     num media                    type clark_grp height_gap
#>   <int> <chr>                   <dbl>     <dbl>      <dbl>
#> 1     1 Superman                    1         2          3
#> 2     2 Superman: The Movie         1         2          3
#> 3     3 Smallville                  2         2          2
#> 4     4 Superman Returns            1         2          3
#> 5     5 Superman & the Mole Men     1         2          3
#> 6     6 Man of Steel                1         2          3

Each character category is replaced with its numeric code. For example, type becomes 1 for Film, 2 for TV Series/TV Show, and 3 for Serial — matching the value labels in the SPSS .sav file.

Dataset-Specific Prep Functions

Every dataset also has its own dedicated prep function if you prefer to be explicit:

superman       <- prep_superman(superman)
hot_ones       <- prep_hot_ones(hot_ones)
mcu            <- prep_mcu(mcu)
mock_jury      <- prep_mock_jury(mock_jury)
tip_jokes      <- prep_tip_jokes(tip_jokes)
candy          <- prep_candy(candy)
candy_simple   <- prep_candy_simple(candy_simple)
football       <- prep_football(football)
huskers        <- prep_huskers(huskers)

Keeping Labels for Plotting

By default, prep functions replace character columns with numeric codes and the original strings are lost. If you need the original values for axis labels or legends in plots, use keep_labels = TRUE. This retains the original character column alongside the numeric one, with a _label suffix:

superman_prepped <- prep_superman(superman, keep_labels = TRUE)

# type is now numeric, type_label has the original strings
superman_prepped |>
  select(num, type, type_label) |>
  head()
#> # A tibble: 6 × 3
#>     num  type type_label
#>   <int> <dbl> <chr>     
#> 1     1     1 Film      
#> 2     2     1 Film      
#> 3     3     2 TV Show   
#> 4     4     1 Film      
#> 5     5     1 Film      
#> 6     6     1 Film

This is useful when you want numeric codes for analysis but readable labels for ggplot2:

superman_prepped |>
  ggplot(aes(x = type_label, y = rt_critics_score)) +
  geom_boxplot()

When to Use Prep Functions

Situation Recommendation
General R analysis, plotting Use the raw dataset as-is
Matching SPSS numeric output Use prep_data() or a dataset-specific prep function
Analysis + plotting with ggplot2 Use keep_labels = TRUE
Exporting to .sav Use export_sav() — it handles conversion internally

Note that exporting to SPSS with export_sav() does not require running a prep function first — the export functions handle numeric conversion internally.

Exporting to SPSS

When you export to SPSS, the package automatically:

  • Converts categorical variables to numeric codes
  • Adds value labels so SPSS displays the category names
  • Replaces NA with -99 and marks it as user-defined missing
  • Adds variable labels describing each column

Dataset-Specific Export Functions

Each dataset has a dedicated export function:

# Export individual datasets
export_superman_sav("superman_data.sav")
export_superman_smes_sav("superman_smes_data.sav")
export_hot_ones_sav("hot_ones_data.sav")
export_tip_jokes_sav("tip_jokes_data.sav")
export_mcu_sav("mcu_data.sav")
export_mock_jury_sav("mock_jury_data.sav")
export_candy_sav("candy_data.sav")
export_candy_simple_sav("candy_simple_data.sav")
export_football_sav("football_data.sav")
export_huskers_sav("huskers_data.sav")
export_interpersonal_sav("interpersonal_data.sav")
export_selfdescriptive_sav("selfdescriptive_data.sav")

# Save to a specific location
export_superman_sav("data/superman_data.sav")

Generic Export Function

You can also use export_sav() with any dataset name:

export_sav("superman", path = "data/superman_data.sav")
export_sav("mock_jury") # Saves to working directory

Exporting a Subset of Variables

Select specific columns before exporting:

# Export only selected variables
superman |>
 select(num, media, year, type, clark_height, rt_critics_score) |>
 export_sav(path = "superman_subset.sav")

# Use tidyselect helpers
huskers |>
 select(date, season, opp, result, starts_with("ne_score")) |>
 export_sav(path = "huskers_subset.sav")

Export All Datasets

Create a folder with all .sav files at once:

export_all_sav(dir = "data/PSYC350_SPSS/")

R vs SPSS: What’s Different?

Aspect In R In SPSS (.sav)
Categorical values Character strings (“Film”, “TV Series”) Numeric codes (1, 2) with value labels
Missing values NA -99 with missing value definition
Variable descriptions In help files (?superman) Variable labels in Variable View
